Mamluk is an engineering company based in the United Arab Emirates. It builds and supports infrastructure software
for organisations in the GCC: a Kubernetes distribution, the Helm charts that run on it, a public container cloud,
and a PHP framework for APIs.

## Repositories

| Repository | What it holds |
|---|---|
| [php](https://github.com/mamlukdxb/php) | PHP container images for the CLI, Apache, FrankenPHP and NGINX Unit, built on the official images, signed by Mamluk and published to GitHub Container Registry, 1x.ax and Docker Hub. |

Pull requests opened on these repositories are not merged. To report a problem or propose a change,
[contact Mamluk](https://mamluk.net/contact/).
